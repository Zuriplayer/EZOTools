# EZOTools

Panel rápido de comandos para teclado, ratón y mando en *The Elder Scrolls Online*.

🇬🇧 Prefer English? Read the [README in English](README.md).

📢 Para soporte, feedback, reportes de errores o sugerencias, únete a nuestro Discord: https://discord.gg/FtP4KapGua
## ✨ Qué hace

Un panel de comandos rápido y un pequeño overlay en pantalla, para teclado, ratón y mando:

- Viajar a tu casa, sala de artesanía o secundaria
- Saltar al líder del grupo, abandonar grupo/instancia
- Reparar el equipo o recargar armas cuando algo está realmente bajo
- Recuperar tu última montura, mascota, compañero o asistente, con historial reciente
- Seguimiento del buff de comida/bebida y reutilizarlo con un clic
- Volver a casas propias o visitadas

## 🎮 Cómo abrirlo

- **Ratón**: clic en el overlay, o clic derecho para el menú de recientes
- **Mando/teclado**: mantener X para comandos, mantener Y para utilidades rápidas (revisa Controles para ver el atajo exacto)
- **Chat**: `/ezo help` para comandos, `/ezo about` para el contacto

## 🌍 Idioma y ajustes

Español e inglés, detectados automáticamente según tu cliente (se puede forzar en ajustes). Ajustes rápidos desde el propio panel, ajustes completos vía LibAddonMenu.

## Requisitos

- The Elder Scrolls Online (PC)
- [LibAddonMenu-2.0](https://www.esoui.com/downloads/info7-LibAddonMenu.html) (obligatorio)
- Opcionales: LibChatMessage, LibDebugLogger, DebugLogViewer, LibSlashCommander

## Instalación

1. Descarga la última versión desde [Releases](../../releases) (o clona este repositorio).
2. Copia la carpeta `EZOTools` dentro de tu carpeta de addons de ESO:
   `Documents/Elder Scrolls Online/live/AddOns/`
3. Asegúrate de tener también instalada la librería LibAddonMenu-2.0.
4. Activa el addon desde la pantalla de complementos del juego.
